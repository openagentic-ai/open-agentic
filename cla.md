## How to Sign

You may sign this CLA in either of the following ways:

### Option 1: Per-PR sign-off (Recommended for now)

Add the following statement to the description of your **first** Pull Request
to the Project:

```
I have read the CLA at https://github.com/openagentic-ai/open-agentic/blob/main/cla.md
and I agree to its terms for this and all future Contributions.

Name:  <your full name>
Email: <your email>
GitHub: @<your-github-handle>
Date:  <YYYY-MM-DD>
```

### Option 2: DCO Sign-off in commits

Use `git commit -s` for every commit. This appends a `Signed-off-by:` line,
indicating that you certify the [Developer Certificate of Origin](https://developercertificate.org/)
and accept this CLA's terms.

```
git commit -s -m "feat: ..."
```

### Option 3: Automated CLA bot (Future)

The Project plans to integrate an automated CLA check (e.g., cla-assistant.io
or a GitHub Action) on Pull Requests. When that is in place, the bot will
prompt new contributors to sign electronically.
