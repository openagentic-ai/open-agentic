# OpenAgentic 暂不优先事项

这些方向暂时记录，不进入当前商业平台 P0 实现范围。优先级以 [产品策略](../product-strategy.md) 和 [商业平台实施计划](commerce-platform.md) 为准：先支持地推商家接入、客户扫码办事和真实预约履约，再按业务证据评估扩展。

## 产品与端

- [ ] 增加更多聊天端和消息渠道
- [ ] 扩展手机自动化 / mobile use agent
- [ ] 做完整 Agent 市场和模板市场
- [ ] 为每个端制作独立的产品能力分支
- [ ] 在没有统一 Gateway 验收前继续扩展新端

## Agent 编排

- [ ] 多 Agent 协作和子 Agent 编排
- [ ] Agent 间角色分工、委派和协商
- [ ] 复杂任务的并行 Agent 执行
- [ ] Agent 自主创建其他 Agent

## 数据与模型

- [ ] 复杂个人知识图谱
- [ ] 自研基础模型或大规模模型微调
- [ ] 复杂模型集成和自动模型竞赛
- [ ] 过早建设大规模向量数据库优化

## 体验与生态

- [ ] 大量 Workflow 模板
- [ ] Agent 插件生态和第三方市场
- [ ] 语音、视觉、穿戴设备等扩展入口
- [ ] 复杂主动规划和长期自主目标系统
- [ ] 面向大规模用户的推荐、增长和社交功能

## 暂不做的原因

这些事项按真实业务需要评估，不要求先完成所有端、所有个人连接器或完整本地运行时。当前扩展依据是：

1. 第一批商家能发布服务并持续使用。
2. 用户能完成预约，商家能接单、履约和反馈结果。
3. 授权、商家数据隔离和重复下单防护通过验收。
4. 试点的留存、成交和人工成本支持继续投入。
5. 新能力能解决已观察到的业务问题。
