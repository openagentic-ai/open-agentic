# OpenAgentic 暂不优先事项

这些方向暂时记录，不进入当前 personal agent P0 实现范围。只有在统一底座、个人身份、记忆、任务、后台恢复、本地运行时、连接器和权限闭环稳定后，再逐项评估。

## 产品与端

- [ ] 增加更多聊天端和消息渠道
- [ ] 扩展手机自动化 / mobile use agent
- [ ] 做完整 Agent 市场和模板市场
- [ ] 为每个端制作独立的产品能力分支
- [ ] 在没有统一 Gateway 验收前继续扩展新端

## Agent 编排

- [ ] 多 Agent 协作和子 Agent 编排
- [ ] Agent 间角色分工、委派和协商
- [ ] 复杂任务的并行 Agent 执行
- [ ] Agent 自主创建其他 Agent

## 数据与模型

- [ ] 复杂个人知识图谱
- [ ] 自研基础模型或大规模模型微调
- [ ] 复杂模型集成和自动模型竞赛
- [ ] 过早建设大规模向量数据库优化

## 体验与生态

- [ ] 大量 Workflow 模板
- [ ] Agent 插件生态和第三方市场
- [ ] 语音、视觉、穿戴设备等扩展入口
- [ ] 复杂主动规划和长期自主目标系统
- [ ] 面向大规模用户的推荐、增长和社交功能

## 暂不做的原因

这些事项并非取消，而是依赖以下前置条件：

1. 所有端已经通过同一套 Agent Application 工作。
2. 个人身份、记忆和任务状态可以跨端连续使用。
3. 任务可以后台执行、暂停、恢复和请求授权。
4. 本地模型运行和云端 API 切换边界清晰。
5. 文件、日历、邮件等基础连接器已经证明真实使用价值。
